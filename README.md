# Localități

Listă dublu înlănțuită cu localități citite din fișier.

## Funcționalități

- citirea localităților din `fisier.txt`
- traversarea în ambele sensuri
- actualizarea populației localităților dintr-un județ cu un procent dat
- dezalocarea memoriei

## Structura de date

`Localitate`: denumire, județ, populație, tip localitate, buget.

## Rulare

Se deschide `Localitati.sln` în Visual Studio. Fișierul `fisier.txt` trebuie să fie în directorul de lucru.
